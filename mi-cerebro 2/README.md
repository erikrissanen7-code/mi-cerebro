# mi cerebro

Persönliches Lernsystem — Vokabeln, Grammatik und Übungen an einem Ort.

**Website:** https://erikrissanen7-code.github.io/mi-cerebro/

## Bedienung

```bash
python3 build.py
```

Erzeugt aus `inhalte/` die komplette Website in `docs/` und die PDFs.
Dateien in `docs/` werden dabei überschrieben — bearbeite immer nur `inhalte/`.

Details stehen in [CLAUDE.md](CLAUDE.md).
